Goal of this computing lab session

In this lab, you will work through a full Bayesian workflow using NIMBLE, starting from simulated data so that every step is fully transparent.

By the end, you should be able to:

  • simulate data from a known data-generating process;
  • write Bayesian models in NIMBLE;
  • perform prior predictive checks;
  • diagnose bad priors;
  • fit a model with MCMC;
  • assess convergence using trace plots, (), and effective sample size;
  • perform posterior predictive checks;
  • identify when a model is misspecified; and
  • improve the model and compare results across specifications.

Define research question

Suppose we are interested in the relationship between a continuous environmental exposure and a continuous health outcome.

How do we build, check, diagnose, and refine a Bayesian model so that it can recover the underlying signal in the data?

1: A first model that is probably too simple

We will begin with a linear Normal model even though the true relationship is nonlinear.

\[ \begin{aligned} y_i &\sim \text{Normal}(\mu_i, \sigma) \\ \mu_i &= \alpha + \beta x_i \end{aligned} \]

This is a useful starting point because the Bayesian workflow is not just about fitting a model once. It is about fitting, checking, diagnosing, and improving.

2: Prior predictive checks

A prior predictive check asks: If our priors were true, what sort of data would the model imply before seeing the observed data?

We will look at three cases:

  1. a bad overly wide prior;
  2. a bad overly restrictive prior; and
  3. a more reasonable weakly informative prior.

Create a grid of exposure values

x_grid <- seq(min(dat$x), max(dat$x), length.out = 100)

2a. Bad prior: wildly too wide

n_sims <- 200

prior_bad_wide <- map_dfr(1:n_sims, function(s) {
  alpha <- rnorm(1, 0, 2)
  beta  <- rnorm(1, 0, 10)
  sigma <- runif(1, 0, 5)

  tibble(
    sim = s,
    x = x_grid,
    y_rep = rnorm(length(x_grid), alpha + beta * x_grid, sigma)

})

2c. More reasonable prior

To make the model easier to fit, we will center the exposure.

dat <- dat %>%

3: Write the first Bayesian model in NIMBLE

We now fit the linear model using reasonable priors.

code_linear <- nimbleCode({
  alpha ~ dnorm(0, sd = 5)
  beta ~ dnorm(0, sd = 2)
  sigma ~ dunif(0, 10)

  for (i in 1:n) {
    mu[i] <- alpha + beta * x[i]
    y[i] ~ dnorm(mu[i], sd = sigma)
  }
})

Prepare data, constants, and initial values

constants_linear <- list(n = nrow(dat))

7: A better model: allow curvature

Because the true relationship is nonlinear, we now fit a quadratic mean structure.

\[ \begin{aligned} y_i &\sim \text{Normal}(\mu_i, \sigma) \\ \mu_i &= \alpha + \beta_1 x_i + \beta_2 x_i^2 \end{aligned} \]

Add a squared term

dat <- dat %>%
  mutate(x2 = x_c^2)

Prior predictive check for the quadratic model

prior_quad <- map_dfr(1:n_sims, function(s) {
  alpha <- rnorm(1, 0, 5)
  beta1 <- rnorm(1, 0, 2)
  beta2 <- rnorm(1, 0, 1)
  sigma <- runif(1, 0.2, 5)

  x_seq <- seq(min(dat$x_c), max(dat$x_c), length.out = 100)

  tibble(
    sim = s,
    x_c = x_seq,
    y_rep = rnorm(100, alpha + beta1 * x_seq + beta2 * x_seq^2, sigma)
  )
})
ggplot(prior_quad, aes(x = x_c, y = y_rep, group = sim)) +
  geom_line(alpha = 0.06) +
  labs(
    title = "Prior predictive check for the quadratic model",
    subtitle = "The model now allows both linear and curved relationships",
    x = "Centered exposure",
    y = "Simulated outcome"
  )

Write the quadratic NIMBLE model

code_quad <- nimbleCode({

10: Sensitivity analysis

The next step in a Bayesian workflow is to ask whether our conclusions are sensitive to reasonable alternative priors.

Here we keep the quadratic model but make the prior on the curvature term a little wider.

code_quad_sens <- nimbleCode({
  alpha ~ dnorm(0, sd = 5)
  beta1 ~ dnorm(0, sd = 2)
  beta2 ~ dnorm(0, sd = 2)
  sigma ~ dunif(0, 10)

  for (i in 1:n) {
    mu[i] <- alpha + beta1 * x[i] + beta2 * x2[i]
    y[i] ~ dnorm(mu[i], sd = sigma)
